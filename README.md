### **Wafilife Website Automation Using Selenium**

This project contains a Selenium automation script for testing the end-to-end product purchase flow of the Wafilife website.

## 📌 Project Overview

The automation script performs an end-to-end shopping workflow by selecting a product, adding it to the cart, providing customer information, and completing the order placement process.

## 🛠️ Technologies Used

- Java
- Selenium WebDriver
- TestNG
- Maven
- IntelliJ IDEA

## ✅ Automated Test Flow

The automation covers the following steps:

1. Open the Wafilife website
2. Search for a product
3. Select a product from the search results
4. View the product details
5. Add the product to the cart
6. Open the shopping cart
7. Proceed to checkout
8. Enter customer information
9. Provide delivery information
10. Select the required order options
11. Place the order
12. Verify the order placement

Make sure the following are installed on your system:

* Java JDK
* Maven
* IntelliJ IDEA
* Chrome Browser

### Install Dependencies

If you are using Maven, add the required Selenium dependency to `pom.xml`.

## ▶️ How to Run

Clone the repository:

```bash
git clone <repository-url>
```

Open the project in IntelliJ IDEA.

Run the Selenium test class:

```text
WafilifeTest.java
```

Or run the TestNG suite:

```text
testng.xml
```

## 🎯 Purpose

The purpose of this project is to practice web automation testing using **Selenium WebDriver** and automate an end-to-end e-commerce purchase workflow.

The project focuses on validating product selection, cart functionality, checkout, customer information submission, and order placement.
